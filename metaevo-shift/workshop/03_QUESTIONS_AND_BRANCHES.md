# 03｜ワーク質問・4ルート分岐仕様

**ワークの基本姿勢：質問は本人のため。回答は非公開。スキップ・修正・途中保存可能。**

## 共通質問（18問）
| ID | 質問文（画面表示） | 回答形式／主要保存フィールド |
|---|---|---|
| Q01 | 今、一番変えたい現実は何ですか？ | 収入・仕事・事業・人間関係・健康・方向性・その他＋任意記述／`currentChallenge` |
| Q02 | あなたは、どんな生き方を大切にしたいですか？ | 価値キーワード（人への貢献・自由・成長・誠実・家族・挑戦・安定・その他）、複数＋自由記述、まだ分からない／`valuesDraft` |
| Q03 | その大切なことを、最近の生活で少しでも感じた場面はありますか？ | 任意短文／`valueEvidence` |
| Q04 | 変えたいと思う理由は、あなた自身の望みですか？ | 自分の意思・周囲の期待・混在・分からない／`motivationSource` |
| Q05 | 望む未来を考えたとき、ワクワクすることと負担に感じることは何ですか？ | 期待・不安をそれぞれ任意選択／`attraction`, `apprehension` |
| Q06 | その目標を明確にすることや、人に話すことには抵抗がありますか？ | 明確化に抵抗、公開に抵抗、両方、特になし、不明／`clarificationResistance`, `sharingResistance`。**『公開しない』は正常な選択。** |
| Q07 | 現在の状態に最も近いものを選んでください。 | A 望みを探索中／B 望みはあるが具体化や公開が負担／C 目標はあるが方法・計画が不明／D 行動の開始・継続が難しい／`route` |
| Q08 | この14日間で、何を少し前進させたいですか？ | `exploration/learning/execution` ＋テーマ／`experiment.theme` |
| Q09 | 14日後、何が起きていれば『前進した』と分かりますか？ | 探索結果、能力の変化、実際の成果等から1つ以上／`evidencePlan` |
| Q10 | 最近、重要だと思っていたのに予定どおりできなかったことはありますか？ | 具体例、該当なし、思い出せない／`incident.summary` |
| Q11 | そのとき、実際には何をしましたか？ | 予定どおり実行・別作業・突発対応・休息・何もしなかった・不明／`incident.actualBehavior` |
| Q12 | その直前に、考えたことや感じたことはありますか？ | 不安・面倒・義務感・失敗への怖さ・方法不明・疲労・何もなし・不明・自由記述／`incident.preResponse` |
| Q13 | その行動の直後に何が起きましたか？ | 安心・達成感・成果・負担増・変化なし・不明／`incident.immediateConsequence` |
| Q14 | 行動を妨げる原因として、何が関係していそうですか？ | 価値不一致・自己評価/公開不安・方法不足・達成見込みの低さ・感情的負担・時間環境不足・優先順位の崩れ・疲労・不明から最大2つ／`hypothesisIds` |
| Q15 | 今日か明日、最も大切な一歩として、何を実行しますか？ | 動詞＋対象＋終了条件／`experiment.firstAction` |
| Q16 | いつ、どんな状況になったら、その一歩を始めますか？ | If–Then 時間・場所・きっかけ／`experiment.startCue` |
| Q17 | もし妨げが出たらどう対応し、何を記録しますか？ | 最小行動（2分等）、支援・再計画・休息、何の時間を置き換えるか（任意）と証拠記録／`experiment.backupPlan`, `evidencePlan` |
| Q18 | 今、最初の2分を試しますか？ | 着手／後で始める／休息する／`firstActionChoice` |

### 原因仮説の意味
`value_gap` 本人の価値観との不一致、`self_worth` 自己評価・他者評価の不安、`method_gap` 方法不明、`low_efficacy` 実行可能と思えない、`avoidance` 不快感への回避の可能性、`opportunity` 時間・環境不足、`urgency` 目先の緊急性、`overload` 疲労・負荷、`unknown` 不明。

**診断ではない。原因仮説として保存し、本人が後で否定・変更できる。**

## ルート別フォロー（初回60分内の追加質問は最大2つ。共通質問の代替でもよい）

### A｜`explore`：望みが本当に分からない
- A1: 最近「充実した」「時間を忘れた」「価値があると思った」場面はどれか？（なければ『まだない』）
- A2: 今後14日間で、興味のある活動をどんな小さな形で試すか？
- 出力は **人生の理念を完成させることではなく、探索実験と証拠**。

### B｜`protect`：望みはあるが明確化・公開に抵抗がある
- B1: 目標を明確化すると、何が負担に感じられるか？（責任・失敗・他者評価・期限・不明）
- B2: 誰にも公開せず、仮の願望として2週間試すなら、どんな一歩が可能か？
- 出力は **個人だけに見える仮案と、自分で選んだ小行動**。公開を絶対に強制しない。

### C｜`plan`：目標があるが計画・方法がない
- C1: 最初の一歩が分からないのか、全体の方法が分からないのか、できる見込みが持てないのか？
- C2: 何を知れば、達成方法について一歩前進したと判断できるか？
- 出力は **実行可能性を確かめる学習実験と、計測できる成果物**。既存の大目標の期限設定を強制しない。

### D｜`execute`：計画はあるが行動できない
- D1: 実行する瞬間に最も起きやすいことは何か？（迷い・不安・別作業・突発依頼・疲労等）
- D2: すぐに行動を始められる時間・場所・環境をどう確保するか？
- 出力は **最重要行動の開始条件、妨げへのプラン、実際の成果指標**。

## Q09の証拠の定義
- 探索：試した行動・学んだこと・価値観の具体化（例『2つの活動を試し、印象をメモ』）。
- 学習：できるようになった技能・実際に作成した計画・検証済の方法（例『顧客への提案手順を1本作り、テスト』）。
- 実行：現実に提供した価値／対象者の反応／売上・契約・実践量など（例『商談を3件実施』）。
- 可能であれば同じ目標について**基準値・14日目の到達値**を入力する。曖昧なら『未測定』とし、Day7で測定方法を修正する。

## 最低限の必須入力
- `Q07 route`、`Q08 experiment.theme`、`Q15 firstAction`、`Q16 startCue` はワークを完全終了する際の必須項目。
- ただし無理に入力させず『途中保存』で進行を止めずに参加可能。Q01–Q06、Q10–Q14の心理・本音項目は任意。
- 選んだ重要行動が当日の最終画面に保存され、翌日に**同じ内容が再表示される**（二重入力なし）。

## 原因判定と分岐の禁止事項
- 失敗への恐怖やプライドを全員の「本当の原因」と扱わない。
- Q06に『公開への抵抗あり』と答えても、開示を促すウィザードを自動表示しない。
- 目標未設定であっても、探索行動の記録・日次画面・14日レビューを利用できる。
- Q10で『該当なし』の人に回避体験の記述を強制しない。
