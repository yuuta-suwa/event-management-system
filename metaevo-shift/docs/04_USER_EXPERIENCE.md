# 04｜日常UX・14日→90日までのサービスブループリント

## 核になる4画面（タブ）
1. **今日**：現在の生き方の軸（1行）／今日のモード／最重要行動1件／開始ボタン／別作業・突発対応・困りごとの入口／夜の確認。
2. **人生の軸**：大切にしたい生き方・理念（仮案含む）／目的・目標／探索テーマ／期限・優先順位／更新履歴。誰にも公開しない。
3. **成長**：行動・技能／学習・現実の成果・価値との一致を4層で表示。記録がない項目は未計測。
4. **振り返り**：直近の行動記録、Day7/14・30/60/90レビュー、実験の更新。
設定・バックアップ・プライバシーはプロフィールメニューへ。

## 初回起動
非公開・個人保存・バックアップ・通知が自動では保証されない点の説明→選択式の初回ワーク→途中保存可能→当日実行→翌日から『今日』へ。

### 初回後の「今日」画面の例
```text
MetaEVO Shift                              Day 03 / 14
あなたの大切なこと：人の役に立ち、成長する（仮）

今日はどんな日？ [前進] [整える] [回復]
今の方向性：顧客への価値を増やす
今日の最重要行動：見込み顧客へ提案を1件送る
もし朝10時に机に座ったら、提案の下書きを5分始める

      [今から始める]
[別のことをしたい] [予定外の対応が入った]
[何から始めるか分からない] [今日は計画を変更する]

今日の前進：行動 未記録／学び 未記録／成果 未記録
[夜の1分確認]
```

## 朝（30–60秒）
- 前日に選んだ行動と開始条件を表示。本人が『今日もこれ』『変更する』『回復する日』を選ぶ。
- 初期画面は最重要行動1つ。『なぜ今これを優先するか』を任意で表示し、何の時間を置き換えるかも本人が確認できる。最大3タップで開始できる。確認に長い質問を挟まない。
- 目標未設定なら『今日の探索』を示す。計画未設定なら『最初の5分を決める』を示す。
- 休息日に変えた場合は『何を守る休息か』を任意記録。仕事の未実行として扱わない。

## 日中（必要時15–30秒）
### ボタンA：行動を開始する
`planned → in_progress → paused/completed`。簡単なタイマーは任意。終了条件は『具体的に何をしたか』と分ける。

### ボタンB：別のことをしたくなった（内的な切替）
- 予定していた行動と、今やりたい別作業を確認。
- 理由を1つ選択（難しい／面倒／不安／今はこちらが重要／疲労／不明）。感情の入力は任意。
- 提案：2分だけ始める／今の行動をさらに小さくする／合理的に再計画／休息。
- 選択だけを記録し、『逃避』という確定ラベルは付けない。

### ボタンC：突発対応（外部からの中断）
- 人命・安全・重大な損失に関わる場合は即対応。入力を強要しない。
- その他は今対応が必要か／委任できるか／後に回せるかを簡単に確認。
- 元の行動の『再開する最初の1操作』と再開予定を保存。予定を過ぎても本人を非難しない。

### ボタンD：何から始めるか分からない
- ①最初の操作が分からない／②必要な能力が足りない／③達成できる気がしない／④負担が大きい。
- ①なら3ステップに分ける、②なら学習・相談、③なら試せる実験に変更、④なら負荷を減らす。

## 夜の確認（1–2分）
- 予定した重要行動の状態：着手／完了／変更／休息／未実行／不明。
- 具体的に進んだこと：行動の証拠（例：提案書を送った）。
- できるようになったこと・学び：任意の1行。
- 結果が出た場合の成果：数値＋単位または文章。まだなければ未計測。
- 本人の価値観に沿う選択だったと思うか：任意の3段階＋未回答。
- 明日の最重要行動を1つ予約。スキップ可。

## 休日・回復日の原則
- 「今日は仕事をしない」という本人の選択も、価値観に沿った前向きな決定になり得る。
- 休日は体調・家族・人生の豊かさ・学びを扱える。仕事の成果率の分母には含めない。
- 休息の理由を強制しない。反復して重要行動が実行されない場合は、本人の同意のもとで週次に見直す。
- 連続記録日数を主要成果としない。長期未入力から復帰する導線を簡単にする。

## Day1–14の導線
| 日 | 主目的 | アプリが行うこと |
|---|---|---|
| Day0 | 初回60分 | 仮の軸・目標/探索テーマ・行動・証拠を決めて初回開始 |
| Day1–3 | 観察と着手 | 行動を小さく始め、状況を記録。心理的原因の断定なし |
| Day4–6 | 最初の改善 | 実行できない場合、障壁に合う小さな条件変更を提案 |
| Day7 | 3分の中間確認 | 「実行可能だったか」「負担は大きくないか」「証拠は取れているか」の3問 |
| Day8–13 | 再実行・検証 | 変更した条件で実行し、結果の変化を確認 |
| Day14 | 20–30分の個人/任意メンター会議 | 実績と欠測を整理、仮説を支持/反証/不十分とし次期実験へ |

Day0は初回ワーク当日。Day1は翌日、Day14は初回の14日後のローカル日付。

## Day14の振り返り体験（5画面程度）
1. **事実**：計画日・実際に着手した日・未記録日・回復日を別表示。
2. **行動の変化**：着手までの障壁、中断・復帰のパターンを観察した件数とともに提示。
3. **成長と成果**：行動の証拠、技能/学び、実成果（未測定なら未測定）、価値との一致。
4. **仮説の検証**：初回の原因仮説は、現状『支持されそう／反例あり／判断材料不足／本人が否定』のどれか。
5. **次の自分の一歩**：14日間で改善する条件を本人が選び、次期実験を開始。

## 30/60/90日の自走化
- Day30：生活に埋め込める行動の条件を見つけたか。週次の記録負担を軽くできるか。
- Day60：本人が自分で原因を調べ、対策を選び、目標を修正できるか。
- Day90：実成果が生まれたか、目標がまだ本人の価値観と一致するか。必要なら中止・変更も合理的な選択。
- アプリへの依存度を増やすことをKPIにしない。支援なしの判断が増えれば前進。

## 体験的な成功例（仮想）
- 目的不明：仕事だけでなく、家族・教育への関心を実際の体験から言葉にできた。
- 計画不能：『できる見込みがない』状態から、方法を小さく検証する学習実験へ移れた。
- 別作業に流れる：焦ると資料整理に移ることを記録し、提案行動を開始できる条件を見つけた。
- 突発対応：必要な緊急対応をしつつ、戻る時間と次の操作を残し、仕事に復帰しやすくなった。

## v2.3 LIFE CLOCK導線
- 4タブ維持。`人生の軸 > 人生の時間`に任意の人生カレンダー／振り返りワークを追加。
- オプトイン後に本人が仮の計画節目（80/90/100/任意）を選び、必要なら生年月日/生年を端末内へ入力。寿命予測でない旨を常時明示。
- 週表示・年表示・質問だけ、から選べる。未設定時は死や寿命の表示なし。
- `後悔したくないこと`→`今日の大切な一歩`で既存日次行動の編集画面へ進む。成長の4層と実績記録を使い、閲覧回数を成果扱いしない。
- 強く不安になる場合は即オフ・削除。毎日の表示、週次の質問はいずれも本人選択。詳しくは`docs/10_LIFE_CLOCK_FEATURE.md`。
