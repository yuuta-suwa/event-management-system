# 10｜新機能詳細仕様 v2.3：人生の時間｜LIFE CLOCK

**正式アプリ名**：MetaEVO Shift（メタエボシフト）―自分革命システム―。LIFE CLOCKはアプリ内の**本人が任意に有効にできる機能**であり、寿命予測ツールではない。既存の4タブ・Q01–Q18・初回60分・14日〜90日運用は変更しない。

## 目的（JTBD）
- 人生の時間が有限であるという事実を、抽象的な知識ではなく本人が選ぶ仮の時間軸で捉える。
- 「死ぬ時に後悔を残さない」という個人の理念を、本人の言葉に置き換え、**今週・今日の大切な行動**へ変換する。
- 仕事・収益だけでなく、家族、健康、友情、学び、挑戦、貢献、休息も正当な優先順位として扱う。
- 他人との寿命・達成度の比較、恐怖や羞恥による強制、死への不安を過剰に煽る表現は使わない。

## 画面配置と優先順位
- 既存4タブは維持。`人生の軸 > 人生の時間` にサブページを追加（5番目のタブを作らない）。
- `今日` の上部に任意表示できる「大切な時間の使い方」カードのみを追加。**初期設定では非表示**。日次最重要行動ボタンより上に大きな要素を置かない。
- `振り返り` 週次・Day14では、設定した場合のみ「後悔したくないことに、どんな一歩を選べたか」を任意表示。
- 既存の「4層の成長」は維持し、LIFE CLOCK使用率を成長指標にしない。

## 機能 L1：有限性の認識｜人生カレンダー
**初回有効化画面（任意、いつでも閉じる）**
1. 趣旨：「人生の時間は有限です。何歳まで生きるかは分かりません。この画面は、あなたが大切にしたい時間を考えるためのものです。」
2. 表示方法を本人が選ぶ：`reflection`（問いだけ）／`year`（今年・今週の時間）／`weeks`（人生カレンダー）。最も穏やかな `reflection` を初期値にする。
3. `weeks` 選択時のみ、年齢計算のための**生年月日（任意）**または**生年（任意）**を入力できる。双方未入力でも `reflection` / `year` は使える。
4. 時間軸は**仮の計画上の到達年齢**。本人が80・90・100または任意の年齢を選択する。**寿命・余命・死亡日を予測していない**ことを画面の近くに常時表示。未選択なら `weeks` の数値表示は保留する。
5. 週1マスのカレンダーを、年／10年単位で整理し、「これまでの時間（色つき）」「仮に置いた節目までの時間（枠線）」を区別。カーソル・色覚差・読み上げに配慮。
6. 例の表示文：`90歳を仮の節目に設定した人生カレンダーです。これは寿命の予測ではありません。`、`今日、どんな時間を大切にしますか？`
7. 避ける文言：`あなたの命はあと◯日`、`残り時間がない`、`今日行動しないと後悔する`、`死ぬまであと◯週間`（確実でない期限を断定するため）。
8. 設定年齢を超えたら負数や「死亡予定超過」を出さず、`設定した仮の節目に到達しました。新たな節目を選ぶか、時間の振り返りに切り替えられます。` と表示する。

**計算仕様**
- `birthDate` が入力されている場合、ローカル日付をUTCの暦日に正規化した日数差から、おおよその経過週を求める。閏年、2月29日、年末、タイムゾーンをテストする。計画節目は生年月日＋設定年齢。2月29日生まれの非閏年は2月末を規約として明記。
- `birthYear` のみなら**概算**として年単位の帯を主表示し、週は `約` を付してよいが正確な生存週数と主張しない。
- 未入力なら暦と残り週を出さず、質問ワークだけ提供。
- 年齢設定は本人が何度でも編集可能。下限1、上限120、本人の現年齢以下なら事前警告または節目到達済み扱いとし、負の残週は計算しない。
- 時刻の経過を秒単位で追い立てるタイマー、寿命予測AI、年齢・病歴から死亡年齢を推測する機能は作らない。

## 機能 L2：後悔しない生き方の問い（任意）
**本人が選べる質問**（回答はすべて非公開・未回答可）：
- `LT01`：人生の最後に振り返ったとき、「やっておけばよかった」と思いたくないことは何ですか？
- `LT02`：本当に大切にしたい人・時間・挑戦は何ですか？
- `LT03`：一年後の自分が今日のあなたに感謝するとしたら、どんな行動ですか？
- `LT04`：今週、仕事・家族・健康・挑戦・休息などの中から、何を意識して優先したいですか？
- `LT05`：この一週間を振り返り、自分の生き方に沿う選択ができた場面はありましたか？
- 上記は心理診断ではない。感情的な負担が生じる場合は即時スキップ・表示停止。本人の価値観に沿って「死」「最期」を含まない穏やかな質問へ切替可能。
- 本人の言葉を `lifeCompass.lifePrinciple` 等の既存項目と双方向リンク可能。ただし自動上書きはしない。適用前に本人が確認する。

## 機能 L3：有限性の認識 → 今日の行動
- `人生の時間` 画面から `今日、大切にする一歩を選ぶ` → 既存の「今日の最重要行動」の**編集画面**を開く。
- 起票時は「なぜその行動を選んだか」を任意で既存 `dayPlan.priorityReason` に保存し、`lifeTime.reflectionToPlanLinks` には**内部参照ID**だけ保存する。
- 例：`家族との時間を後回しにしたくない` → `今夜20分、スマホを置いて一緒に話す` → 当日の記録 → 週次で本人が選んだ体験を振り返る。
- 仕事以外の重要行動や休息も正当な一歩。**LIFE CLOCKから操作しただけで「実行済み」にしない**。行動の証拠は既存4層で管理。
- 振り返りでは「限りある時間をどう使うか、何かを自分で選べたか」という**質的な証拠**を表示。死への恐怖の強さ、残週数、アプリ閲覧回数を達成度に換算しない。

## 初回60分ワークへの組み込み
- **08:00〜18:00「生き方を探索」のQ02の補助カード**として、任意の `LT00`「人生の最後に振り返ったとき、大切にしていたいものは何ですか？」を表示できる。主質問Q02への回答の参考にするだけで、**Q01–Q18の追加必須質問にしない**。
- Q02中の任意カードは最大60秒。講師は説明を追加せず、Q02の5分の中で提示。心理的抵抗がある場合は『将来の自分から考える』へ切り替え。
- 0〜8分のアプリ紹介では『人生の時間は、希望する人が後から有効にできます』と一言説明するにとどめる。
- **カレンダーの年齢設定は初回60分に強制しない**。ワーク終了後、「人生の軸」から任意セットアップ。

## 初期文言、共有・プライバシー・安全
- `enabled` 初期値 false、ホームのカードも初期値 `off`。プッシュ通知も自動起動もオフ。
- ホーム表示を自分で有効化しても、露骨な死亡リマインダーを毎日出さず、`今日、大切にすることは？` の穏やかな表示にする。
- **人生の時間に関する情報は端末内のみ**。誕生情報・死生観・後悔の記述・寿命仮定は将来のメンター連携の共有データから既定で除外する。
- オフにする／非表示にする／この機能の記録だけ削除する／端末データを全削除する、を提供。
- 不快感・喪失体験・不安が強まった場合、恐怖を煽ることなく表示を停止できる。深刻な苦痛を自覚した際は適切な専門的支援を求める案内を提供。
- 未成年や高い心理的負担が想定される利用者には、死に関する表現を自動で提示しない。年齢確認を要求してデータ収集を増やすのではなく、常に任意機能とする。

## リスクと品質基準
| リスク | 必須対策 |
|---|---|
| カレンダーが「死亡予測」と誤解される | 一画面内に仮の節目・寿命予測ではない旨を常時併記 |
| 不安・焦燥・自己否定が高まる | 既定オフ、穏やかな言葉、即時停止、強い通知なし |
| 仕事の生産性に偏る | 人間関係・健康・休息を選択可能、業務実行との混同禁止 |
| プライベートな死生観が漏れる | ローカル保存、個別削除、共有除外、バックアップ機密性案内 |
| 数字を見るだけで満足する | 人生理念・選択理由・実行と振り返りへつなぐ導線 |
| 偽の達成感 | カレンダー閲覧回数を「成長」として表示しない |
