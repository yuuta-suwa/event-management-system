# 07｜技術構想・データ保護・将来のAIメンター’s会議室連携境界

## 技術方針（初期版）
- **PWA・ローカルファースト**。React + TypeScript + Vite、IndexedDB（Dexie等）、Zod等で入力検証、Service Workerでオフライン対応。
- 利用者ごとのログインなし・サーバー側個人データ保存なし。ユーザーの端末に保存。
- **分析は本人記録に基づく決定規則（ルールエンジン）**。LLM APIキー・従量課金・ChatGPTアカウント共有を必須にしない。
- 参加者の個人用データは初期状態で他者へ一切共有しない。講師にはデモ画面のみ。
- 端末データを本人がJSONでエクスポート・復元・削除できる。バックアップ失敗時の復旧とスキーマ移行テストが必須。
- ストレージ消去や端末破損時にはデータが失われ得る。バックアップファイルは初期版では平文なので保存先注意を明示。
- iOSはSafariとホーム画面アプリでローカル保存領域が異なる場合があるため、**事前にホーム画面へ追加してから初回入力**を基本とする。

## メイン機能モジュール
`workshop`（Q01–Q18と分岐）／`values-goals`（価値観と目標履歴）／`planner`（14日・当日最重要行動）／`events`（開始・中断・内的切替・復帰）／`reviews`（日次/7/14/30/60/90）／`behavior-rules`（純関数・ルールID）／`evidence`（4層の実績）／`storage`（ローカル保存と移行）／`privacy`（バックアップ・削除）／`adapters`（未使用の将来連携境界）。

## 重要なイベント
- `PLAN_CREATED`, `ACTION_STARTED`, `ACTION_PAUSED`, `ACTION_COMPLETED`, `INTERNAL_SWITCH`, `EXTERNAL_INTERRUPT`, `ACTION_RESUMED`, `REPLAN`, `REST_CHOSEN`, `DAILY_REVIEW`, `HYPOTHESIS_REVISED`, `GOAL_REVISED`, `EVIDENCE_ADDED`。
- 全イベントに `id`, `kind`, `occurredAt`, `localDate`, `planId`, `payload` を付与。複数回タップでイベントが重複しないよう冪等制御。
- 当初の予定と変更後の予定を両方残す。ただし本人が全削除できる権利を優先。

## アプリの構造と将来拡張（現時点では接続しない）
```text
MetaEVO Shift PWA
├─ 本人だけのデータ：価値観／目標／日次行動／成果
├─ ローカル行動支援ルール
├─ 本人向けレポート
└─ Optional Integration Adapter（将来・現状は未使用）
       ├─ 同意と共有範囲の確認
       ├─ 共有する要約・期間の本人選択
       ├─ 手動プレビュー・編集・送信確認
       └─ AIメンター’s会議室システム（将来の連携先）
```

### 将来の連携契約の原則
- 初期版は**「連携するボタン」すら実装不要**。今はデータモデルの拡張可能性だけ確保する。
- 将来の接続では、取得先の認証方式・API対応・組織設定が分かるまで実装を前提としない。
- 本人が個別に選択したデータだけを共有。感情や非公開願望、第三者情報は**デフォルト除外**。
- 共有前に対象（例：14日間の行動要約、目標の進捗）と送信先、保存範囲をプレビュー。
- 共有停止・同意撤回・送信履歴の確認を提供。共有済みデータの削除は連携先の能力に依存し、保証しない。
- 連携先のAIの提案は本人の意思決定補助。本人の人生理念や目標を無断で変更しない。

### 将来の抽象インターフェース（仕様だけ）
`InsightExportV1 = { version, generatedAt, period, selectedGoalSummary?, selectedBehaviorSummary?, selectedOutcomeEvidence?, excludedPrivateFields: true, consent: { confirmedAt, targetName, scope } }`。
これは現在使えるAPIを示すものではなく、将来接続先が確定したときの設計境界。

## アクセシビリティとUX
- モバイル最小320px、タップ領域44px目安、キーボード操作、スクリーンリーダー用ラベル、フォーカス表示、モーション削減。
- ダークネイビー×ゴールドはアクセントのみ。本文は明瞭で読みやすくする。
- 生き方・価値・心理的反応はセンシティブ。外部の解析ログ・エラートラッカーに本文を送らない。
- 文字入力は最小限、選択式・途中保存・後から修正を重視。入力・操作の失敗時に自己評価を下げる文言を表示しない。

## 未実装・未確認事項を明示
- 完全な無料運用を保証しない。静的ホスティングの制限・ドメイン・保守・サポート費用を別途確認する。
- Web Push/OS通知は端末や許可に依存するので、継続の必須条件にしない。
- 現在は個人データを別端末に自動同期しない。データ復元は本人操作。
- 生成AIが必須の自然言語分析は対象外。ルールエンジンができるのは事実の集計・定型的な提案まで。

## v2.3 TIMEモジュール
`life-time`を追加。設定、任意の反省メモ、当日の行動への内部参照のみ保存。出生情報は任意、端末内で処理。仮の計画節目は寿命予測でない。v2.0保存データはv2.1へ移行し、`lifeTime.enabled=false`で初期化する（古いデータを削除しない）。`InsightExportV1`などの将来の共有要約に出生情報・後悔の記述・死生観・仮の到達年齢を含めない。
