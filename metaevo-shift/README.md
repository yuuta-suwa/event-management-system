# MetaEVO Shift 最終構想・設計 v2.3（LIFE CLOCK追加）

> **正式名称：MetaEVO Shift（メタエボシフト）―自分革命システム―**。表記・PWA・コード名は `00_BRAND_NAMING.md` を優先する。


**状態：構想と設計仕様の確定版／アプリ本体は未実装。**

## 目的
「稼ぎたい・成功したい・自己実現したい」と考えながら、理念・目標・計画・重要行動を避けたり、優先順位が崩れたりする人が、本人の意思で望みを見つけ、行動を選択し、成果と成長を確認し、自己改善を続けられるようにする。

### 最上位成果
- 人生理念・生き方：本人が自分の言葉で探究・更新できる。
- 行動：毎日（休日・休息日も含む）の選択が本人の大切な価値に沿う。
- 目標：目的に合う成果指標に実際の進捗が出る。成果が出なければ戦略を検証する。
- 自律性：記録やアプリの指示に依存せず、本人が判断と改善を自走できる。

## 確定した体験
- **事前準備**：アプリをスマートフォンに導入。iOSのホーム画面版とSafariの保存領域の違いを説明。
- **初回60分**：8分の価値・使い方説明→52分のアプリ入力ワーク。目的・目標が未定でも開始可。回答は即時保存し二重入力なし。
- **Day1–14**：朝30–60秒、行動時は必要な場面だけ15–30秒、夜1–2分。休息日も選択可能。Day7に軽い確認。Day14に振り返り。
- **Day15–90**：本人が必要性を選びながら継続。Day30/60/90で行動定着・自己判断・成果を評価する。14日では習慣完成を保証しない。
- **AIメンター’s会議室連携**：将来のオプトイン拡張。現バージョンに認証・連携・データ自動送信を実装しない。

## v1.0からの主要な更新
- 人生理念・生き方と「結果と自己価値を混同しない」導入を追加。
- 本音が分からない人／本音はあるが認めにくい人／計画できない人／行動を避ける人を、固定ラベルではなく現在の状態で分岐。
- 目標設定・計画作成と行動の実行を切り離し、各ルートで必ず14日間の現実の実験を持つ。
- 行動・能力/学び・成果/結果・価値との一致を分けて表示。根拠のない「自己実現率」は作らない。
- 朝・日中・夜・休日の運用と「前進/整える/回復」の選択を明確化。
- 7日、14日、30日、60日、90日の検証と再設計を追加。
- 将来のAIメンター会議室連携用の境界を定義し、初期版とは分離。

## 禁止事項
- 未実行を「逃避」だと断定すること、目標未確定を人格評価すること。
- 目標の公開・ワーク回答の共有を強制すること。
- 14日で習慣化する、収入が増える、心理治療できると保証すること。
- 「仕事の活動量」を「人生の成長」や「成果」と同一視すること。
