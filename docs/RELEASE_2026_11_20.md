## 変更内容
帳簿の「取引履歴」から、記録を**理由をつけて直せる**ようにしました。直した内容は消えない履歴として残ります。

| 直せる記録 | 直せる項目 | 備考 |
|---|---|---|
| 経費 | 項目名・金額・備考 | 立替・店舗支払から作られた経費は**備考のみ**（金額・項目名は元の記録を直す） |
| 参加費立替 | 立て替えた人・本来の支払者・立替額・立替日・証憑メモ | 回収済み額より小さくは不可。立替額を直すと状態（未回収/一部回収/回収済み）を自動で再計算 |
| 経費立替 | 立て替えた人・費目・支払先・立替額・支払日・証憑メモ | 精算済み額より小さくは不可。承認済みなら、計上済みの経費も同じ内容に自動で直る（二重計上にならない） |

- **理由は必須**（空・空白だけは不可、300文字まで）。
- **履歴**: 日時・編集した人・対象・変更前→変更後・理由。帳簿ページの「編集履歴」、各記録の編集画面、CSVに出ます。履歴は編集・削除できません。
- **誰が直せるか**: 帳簿を扱える人（システム管理者・担当イベントの管理者・決裁権者）。受付スタッフ・集金担当・他イベントの管理者は不可（サーバー側で判定）。

- 取消済みの立替・取消済みの経費は直せません。
- **対象外**（それぞれの元の画面で取消・訂正する運用）: 集金・内部送金・店舗支払・チケット売上。入金・預り金の残高と整合させる必要があるため。

# 参加者名簿の編集・過去の記録の入力

## 過去の記録の入力（参加者名簿 →「過去の記録を入力」）
1月からの記録など、システムに入っていない過去の参加者・入金・出欠を名簿に入力します。
- **まとめて貼り付け**: Excel・スプレッドシートからコピーして貼り付け（タブ区切り/CSV、最大300人）。1行目に見出し（名前・フリガナ・電話・メール・入金・金額・入金日・入金方法・出欠・受付日時・紹介者・備考）があれば列の順番は自由。**名前だけあれば登録可**。テンプレートCSVをダウンロードできます。
- **1人ずつ追加**もできます。
- **「確認する」で何も保存せずに結果を確認**（新規／名簿にいる方／登録済み／エラーを行ごとに表示）→「登録する」。
- **メール・LINEなどの通知は一切送りません**（入金確認メール・QRチケット・管理者通知なども作りません）。
- 定員や申込締切に関係なく、**終了済みイベントにも入力できます**。イベントがない場合は先にイベントを作成（過去の日付・状態「終了」）。
- 入力した入金は売上・**年次/月次の帳簿**に反映されます（イベントの開催日で集計）。受付済みの人は参加人数に入ります。
- **同じ内容を2回入れても二重登録されません**（登録済みはスキップ）。同じ人の判定は、メール一致 → 電話＋同じ名前。電話だけ同じ別人（家族など）は別人として登録。連絡先なしの同名はスキップ。
- 名簿にいる方（同じメール）は、新しい人を作らず**このイベントの記録だけ追加**し、既存の情報は書き換えません。
- 入れられる人: システム管理者、そのイベントの管理者。
- 集金（現金の預り）・送金・経費の記録は対象外です（これらは帳簿・集金・立替の画面から入力）。

## 参加者名簿の編集（名簿の各行の「編集」）
- **参加者の情報**: 名前・フリガナ・電話・メール・性別・年齢・職業・紹介者・SNS・備考（同じ人の**ほかのイベントにも反映**）。
- **このイベントでの入金・出欠**: 未入金→入金済み（金額・入金日・方法）、入金額・日付・方法の訂正、未受付→受付済み（受付日時）、受付日時の訂正、受付の取消、欠席。メール・LINEの通知は送りません。
- できないこと: 入金済み→未入金（返金・取消は入金の画面から）、退出の記録がある人の受付取消、取消・返金済みチケットの入金・出欠変更（名前・連絡先は直せます）。
- **理由は必須**。誰が・いつ・何を（変更前→変更後）・なぜ、を編集画面の履歴に残します（監査ログ `ROSTER_ENTRY_EDITED` / `ROSTER_BACKFILL_CREATED`）。同じ人の履歴は、ほかのイベントの行からも見えます。
- 同時編集の保護あり（画面を開いたあとに他の人が直していたら止めて案内）。

# 年次・月次の帳簿から直接編集（人数・名簿・イベント名）

帳簿 →「年次・月次の帳簿」の画面から、そのまま編集できます（システム管理者・そのイベントの管理者。決裁権者は閲覧のみ）。
- **イベント別の表の「編集」列**: 「参加者を入力」（過去の記録を入力画面へ）／「名簿を編集」（そのイベントの名簿へ）／「名前を変更」。
- **月の参加者履歴の各行の「編集」**: 名前・連絡先・入金・出欠（受付）を理由つきで直せます。参加人数・販売枚数・売上は、これらの記録から自動で集計されるので、直すとすぐ帳簿に反映されます。
- **「過去のイベントを追加」**（画面の下）: 記録のない月（例: 1〜8月）のイベントを追加し、そのまま参加者（人数・名簿・入金）の入力へ進めます。追加したイベントは状態「終了」・非公開で、申込・通知は出ません。カテゴリーは「過去の記録」が自動で作られます。
- **イベント名の変更**: 理由必須。変更前後・理由・直した人が履歴（監査ログ `EVENT_RENAMED`）に残ります。
- マイグレーションの追加はありません。
