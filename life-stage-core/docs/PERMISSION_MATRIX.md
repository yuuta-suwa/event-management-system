## アプリ別権限
- APP01／APP02／APP03 は**完全に独立**。APP01 の権限で APP02・APP03 は使えない。
- 無効アプリ（LIFE_ACCOUNTING 等）は付与不可。
- APP02 の LEGACY モード資格・APP03 の認定審査者／事業管理者は各APP側の権限として後日追加（共通基盤の `admin_roles` を拡張するか APP 固有テーブルで持つかは Q-06）。
